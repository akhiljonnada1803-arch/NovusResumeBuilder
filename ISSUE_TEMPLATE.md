# Issue Template for Novus Resume AI

Please use the issue templates under [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/):

- 🐛 [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md)
- ✨ [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md)

When submitting an issue, please ensure you include:
1. Clear steps to reproduce the issue.
2. Operating system and environment version (Node.js, Browser, or Tauri desktop version).
3. Any relevant terminal logs or screenshots.
